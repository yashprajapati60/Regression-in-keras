# 📈 Regression Modeling using Keras (Deep Learning)

## 📌 Overview

This project demonstrates **regression modeling using Keras**. The goal is to predict continuous numerical values by training a **fully connected neural network (ANN)** on structured data.


---

## 🧠 Model & Approach

* **Machine Learning Type:** Supervised Learning
* **Problem Type:** Regression
* **Model:** Artificial Neural Network (ANN)
* **Framework:** Keras (TensorFlow backend)
* **Loss Function:** Mean Squared Error (MSE)
* **Optimizer:** Adam

---

## 🔹 Project Workflow

* Loaded and inspected the regression dataset
* Performed data preprocessing and feature scaling
* Split data into training and testing sets
* Built a **neural network regression model** using Keras
* Configured loss function and optimizer
* Trained the model over multiple epochs
* Evaluated model performance on test data
* Visualized training loss and predictions

---

## 📊 Results & Performance

* **Model Type:** Deep Learning Regression
* **Evaluation Metrics:**

  * Mean Squared Error (MSE)
  * Mean Absolute Error (MAE)
* **Outcome:**

  * Model successfully learns continuous value patterns
  * Reduced prediction error over training epochs
  * Smooth convergence indicating effective learning
